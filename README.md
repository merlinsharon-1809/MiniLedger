# MiniLedger

A full‑stack money‑lending tracker built with React Native (Expo) and a Node/Express backend.

> **NOTE**: This repository implements the internship assignment specification.

## Features
- Mock OTP authentication via phone number
- Loan creation, listing, repayment, and overdue detection
- Glass‑morphism UI components
- Secure JWT authentication
- Prisma ORM with PostgreSQL
- Automated backend tests (Jest & Supertest)
- Mobile app tests (React Native Testing Library)
